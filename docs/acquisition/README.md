## Décisions commerciales à conserver

Casablanca prioritaire. Rabat sur demande depuis Casablanca. Aucune autre ville de prise en charge actuellement. Priorité MRE, touristes et vacanciers ; locaux ensuite. Voitures touristiques classiques, catalogue indicatif ; pas de luxe, van, utilitaire, mariage ou location professionnelle. Minimum trois jours, maximum six mois calendaires. Livraison gratuite aux gares/aéroports desservis, modalités convenues à l’avance. Prix journaliers indicatifs existants conservés. Demande par WhatsApp, sans paiement en ligne ni réservation automatiquement confirmée.

## Comment laisser une trace après chaque intervention

1. Lire ce fichier et les dernières décisions ; ne pas reprendre les anciens audits comme si rien n’avait été fait.
2. Donner un identifiant à l’action, noter le besoin et son état avant modification.
3. Enregistrer les sources datées et les preuves dans un dossier de session ; synthétiser sans recopier intégralement les pages tierces.
4. Ajouter une ligne au journal : action réelle, fichiers/URL, vérification, résultat, limite, prochaine étape.
5. En cas de changement public : conserver PR, commit, déploiement et contrôle public. Un brouillon n’est pas une publication ; un envoi n’est pas une indexation.
6. Conserver l’historique et ajouter une décision qui remplace explicitement la précédente lorsqu’une règle change.
